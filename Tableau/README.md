# COVID-19 Portfolio — Tableau Dashboard

## Overview

This Tableau dashboard provides an interactive analysis of the global impact of COVID-19.

The project explores COVID-19 cases, deaths, vaccination, healthcare pressure, testing, and differences between countries and continents.

The dashboard was developed to transform large amounts of COVID-19 data into clear, interactive visualizations that allow users to identify trends, compare countries, and explore relationships within the data.

### Tools Used

* Tableau
* SQL Server
* SQL Server Management Studio (SSMS)
* Excel
* Data visualization
* Calculated fields
* Interactive filters
* Dashboard actions

---

# Dashboard Overview

The Tableau project brings together multiple visualizations into an interactive COVID-19 analysis dashboard.

The analysis focuses on:

* COVID-19 cases
* COVID-19 deaths
* Case fatality rates
* Vaccination
* Healthcare pressure
* Testing
* Reproduction rates
* Geographic differences
* Demographic and socioeconomic factors

# Key Visualizations

## COVID-19 Cases

The dashboard examines how COVID-19 cases changed over time and how infection levels differed between countries and continents.

### Visualizations

* New Cases Over Time
* Total Cases by Country
* Top Countries by Cases
* Global Case Distribution
* Country Comparisons

These visualizations help identify periods of increased COVID-19 activity and differences in infection levels across countries.

---

## Mortality Analysis

The mortality analysis examines COVID-19 deaths and case fatality rates.

### Analysis

* New Deaths Over Time
* Total Deaths by Country
* Death Rate Comparisons
* Case Fatality Rate
* Deaths by Continent

The analysis provides a comparison of mortality outcomes across different geographic areas.

---

## Vaccination Analysis

The dashboard explores the global rollout of COVID-19 vaccinations.

### Analysis

* Vaccination Trends
* People Vaccinated
* Fully Vaccinated Population
* Vaccination Comparisons

Interactive filters allow users to investigate vaccination patterns across countries and time periods.

---

## Healthcare Pressure

The dashboard examines the effect of COVID-19 on healthcare systems.

### Analysis

* ICU Patients
* Hospital Patients
* ICU Trends
* Hospitalization Trends
* Hospital vs ICU Activity

These visualizations provide insight into healthcare demand during different stages of the pandemic.

---

## Testing Analysis

The testing section examines COVID-19 testing activity and test outcomes.

### Analysis

* Total Tests
* New Tests
* Testing Trends
* Positivity Rate
* Tests Per Case

This allows users to compare testing activity and positivity across different countries and periods.

---

## Reproduction Rate

The dashboard includes analysis of the COVID-19 reproduction rate.

The reproduction rate is used to explore changes in the spread of COVID-19 over time and differences between countries.

Users can filter the analysis by country, continent, and time period.

# Interactive Features

The Tableau dashboard includes interactive features that allow users to explore the data dynamically.

### Filters

Users can filter the dashboard by:

* Country
* Continent
* Year
* Date
* COVID-19 indicator

### Dashboard Actions

Interactive dashboard actions allow users to select information in one visualization and explore the corresponding information in other visualizations.

For example:

**Select a continent → compare countries → investigate cases, deaths, vaccination, and healthcare pressure.**
