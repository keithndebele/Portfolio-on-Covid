# COVID-19 Portfolio — Power BI Dashboard

## Overview

This Power BI dashboard provides an interactive analysis of the global impact of COVID-19, covering cases, mortality, vaccination, healthcare pressure, testing activity, and demographic and socioeconomic factors.

The dashboard is designed to allow users to explore COVID-19 trends across countries and continents and identify patterns in the pandemic data.

### Tools Used

* Microsoft Power BI
* SQL Server
* SQL Server Management Studio (SSMS)
* DAX
* Power Query
* Data visualization

---

# Dashboard Structure

The dashboard contains **six interactive pages**, each focusing on a different aspect of the COVID-19 pandemic.

---

## PAGE 1 — Executive Overview

Provides a high-level summary of the global COVID-19 situation.

### Key Metrics

* Total Cases
* Total Deaths
* Vaccination Rate
* Peak ICU Patients
* Total Tests

### Visualizations & Filters

* Global Impact Map
* Country Slicer
* Year Slicer
* Continent Slicer

This page provides a starting point for exploring the overall scale and geographic distribution of COVID-19.

---

## PAGE 2 — Cases & Mortality

Examines how COVID-19 cases and deaths changed over time and across countries.

### Analysis

* New Cases Over Time
* New Deaths Over Time
* Top 10 Countries by Cases
* Global Impact Map
* Reproduction Rate

This page helps identify major case and mortality trends and provides geographic context for the spread of COVID-19.

---

## PAGE 3 — Vaccination

Analyzes the global rollout of COVID-19 vaccines.

### Analysis

* Vaccination Rollout
* Top 10 Vaccinated Countries
* Vaccination Coverage Map
* New Vaccinations
* Booster Rollout

This page allows users to explore differences in vaccination activity and coverage across countries and over time.

---

## PAGE 4 — Healthcare Pressure

Examines the pressure COVID-19 placed on healthcare systems.

### Analysis

* Peak ICU Patients
* Top Countries by ICU Patients
* Hospital vs ICU Admissions
* Hospitalization Heatmap
* Hospital Patients

The page provides insight into hospitalization and intensive-care trends and how healthcare demand changed during the pandemic.

---

## PAGE 5 — Testing

Analyzes COVID-19 testing activity and testing outcomes.

### Analysis

* Total Tests
* Testing Activity Over Time
* Positivity Rate
* Tests Per Case
* Positivity vs Cases

This page explores differences in testing intensity and positivity across countries and time periods.

---

## PAGE 6 — Demographics & Outcomes

Explores relationships between COVID-19 outcomes and demographic, economic, and population characteristics.

### Analysis

* GDP vs Vaccination
* Population Density vs Cases
* Median Age vs Case Fatality Rate
* Key Influencers
* Decomposition Tree

The analytical features on this page allow users to explore factors associated with differences in COVID-19 outcomes.

---

# Interactive Features

The dashboard includes interactive filtering and cross-analysis capabilities.

Users can explore the data by:

* Country
* Continent
* Year
* Time period
* COVID-19 indicators

Selecting data points in one visualization can also affect related visualizations, allowing users to investigate specific countries, periods, and trends.
