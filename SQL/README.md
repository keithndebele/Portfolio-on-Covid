# COVID-19 SQL Data Analysis

## Project Overview

This project uses SQL Server to analyze COVID-19 cases,
deaths, vaccinations, testing and hospitalizations.

The analysis focuses on identifying trends, relationships
and differences between countries and continents.

## Tools

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL
- Power BI
- Excel

## SQL Analysis

The SQL queries are organized into the following sections:

1. Data Cleaning
2. COVID-19 Analysis
3. South Africa Analysis


## Key Questions

- Which countries had the highest infection rates?
- How did COVID-19 death rates differ between countries?
- How did vaccination rates change over time?
- What were the monthly hospitalization trends?
- How did COVID-19 outcomes differ between continents?
- Is there a relationship between diabetes prevalence and COVID-19 outcomes?

## Dashboard

The results of the SQL analysis were used to create
an interactive Power BI dashboard.
