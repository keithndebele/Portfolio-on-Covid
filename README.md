# COVID-19 Data Exploration Portfolio

## Project Overview

This project demonstrates my SQL and  data visualization skills by exploring global COVID-19 data. The analysis focuses on infection rates, death rates, vaccination progress, and other key metrics using SQL queries and interactive visualizations.

## Tools Used

- SQL
- MySQL
- Tableau
- Git & GitHub
- SQL Server Management Studio 22
- Power BI

## Project Objectives

- Clean and explore COVID-19 data
- Perform data analysis using SQL
- Create reusable SQL queries
- Build interactive Tableau dashboards
- Present insights through data visualization

## SQL Skills Demonstrated

- SELECT Statements
- WHERE Filtering
- GROUP BY
- ORDER BY
- JOINs
- Common Table Expressions (CTEs)
- Window Functions
- Aggregate Functions
- Views
- Temporary Tables

## Dashboards

The Dashboard visualizes:

- Total Cases
- Total Deaths
- Death Percentage
- Vaccination Progress
- Country Comparisons
- Global Trends
